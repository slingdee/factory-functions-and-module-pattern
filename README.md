 Factory Functions and the Module Pattern
📌 Overview

This project demonstrates how factory functions and the module pattern can be used in JavaScript to create objects, organize code, and achieve data privacy.

🏭 Factory Functions

A factory function is a function that returns an object.
They allow easy object creation without using classes or constructors.
Useful for code reuse and creating multiple object instances.

📦 Module Pattern

The module pattern uses factory functions and closures.
It hides private data and exposes only the necessary methods (public API).
Helps with encapsulation and keeps code clean.

Functions in javascript form closures. A closure refers to the combination of a function and the surroundig state in which the function was declared.
